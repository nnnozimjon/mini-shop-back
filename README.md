
# MINI SHOP Backend

Backend-приложение для проекта **MINI SHOP**, разработанное с использованием современных технологий.  
Проект находится **в активной разработке** и ещё не завершён.


## 🚀 Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd mini-shop-backend
````

---

### 2. Установить зависимости

```bash
npm install
```

или

```bash
yarn install
```

---

### 3. Настроить переменные окружения

Создайте файл `.env` в корне проекта со следующими переменными:

```env
# PostgreSQL
DB_HOST=
DB_PORT=
DB_USER=
DB_PASSWORD=
DB_NAME=

# JWT
JWT_SECRET=
JWT_EXPIRES_IN=

# Redis
REDIS_HOST=
REDIS_PORT=

# Storage / File uploads
STORAGE_URL=
```

---

### 4. Запустить сервер

```bash
npm run dev
```

или

```bash
yarn dev
```

После запуска сервер будет работать по умолчанию на:

```
http://localhost:3000
```

---

## 🛠 Используемые технологии

* Node.js
* TypeScript
* Express.js / Nest.js (уточните по проекту)
* PostgreSQL
* Redis
* JWT авторизация
* REST API
